# Сборки для Android

| Файл | Версия | Примечание |
|---|---|---|
| `preferans-0.1.0.apk` | 0.1.0 (versionCode 1) | Первая тестовая сборка |

- Release APK, JS-бандл встроен: Expo Go и Metro не нужны.
- Android 7.0+ (minSdk 24), ABI arm64-v8a и armeabi-v7a (на x86-эмуляторе не запустится).
- Подписан debug-ключом: для установки на свой телефон (разрешить установку из неизвестных источников), не для Google Play.
- На реальном устройстве ещё не проверялась.

Собрать заново: `ANDROID_HOME=/путь/к/sdk ./scripts/build-apk.sh`.
