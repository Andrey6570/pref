# Колода «Русский стиль»

Издание Dondorf GmbH, 1911 год (по данным Wikimedia Commons). Общественное достояние.

Источники (Wikimedia Commons, лицензия Public domain):
- https://commons.wikimedia.org/wiki/File:Russian_playing_card_deck_Russian_style_1911_original.png
- https://commons.wikimedia.org/wiki/File:Russian_playing_card_deck_(face_cards)_Russian_style_1911_original.jpg

Файлы получены скриптом `scripts/make-cards.py`: картинки и рубашка вырезаны с листа,
К♦ собран из верхней половины двусторонней карты, числовые карты 7–10 собраны из
чистого бланка и очков, вырезанных с оригинальных карт.
